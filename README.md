# Utility Hub 🛠️

**Utility Hub** is a fast, lightweight, and privacy-friendly collection of browser utilities that run 100% locally in your browser. 

Deployed statically on GitHub Pages with zero server dependencies, zero authentication, and zero database requirements.

---

## ✨ Features

- ⚡ **100% In-Browser Computation**: All tools process data locally on your device.
- 🔒 **Privacy-First**: No data tracking, logging, or third-party server requests.
- 🌓 **Dark & Light Mode**: Default to system theme preference with persistence in `localStorage`.
- 📱 **Progressive Web App (PWA)**: Offline support and installable application manifest.
- 🔍 **Instant Search & Category Filter**: Quickly locate utilities with real-time text search and tag filters.
- 🌐 **Static & GitHub Pages Ready**: Built for static hosting.

---

## 🚀 Included Utilities

- ⏱️ **Pomodoro Focus Timer**: Focus/Break sessions with Web Audio chime, custom durations, and task tracker.
- 📱 **QR Code Generator**: High-resolution QR codes with customizable colors, error correction, and PNG export.
- 🔐 **Password Generator**: Secure, customizable passwords with strength meter and batch generation.
- 📝 **JSON Formatter & Validator**: Format, validate, and minify JSON data with sample JSON and download.
- 🔤 **Base64 Encoder / Decoder**: Encode and decode text or files into Base64 / URL-safe Base64.
- 🆔 **UUID / GUID Generator**: RFC4122 v4 UUID generator with batch generation and `.txt` export.
- ⏳ **Social Video Downloaders (YouTube, Twitter/X, Instagram)**: Coming Soon placeholders.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Vanilla CSS with modern CSS variables, glassmorphism, and responsive CSS grid
- **Icons**: Lucide React
- **PWA**: Service Worker & Web Manifest

---

## 💻 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/kaisarnajar/utility-hub.git

# Navigate to project directory
cd utility-hub

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
